# 페르소나 인지 워크스루 (사전 점검)

> 이 문서는 사용성 테스트 결과가 아닙니다. 실제 사람 없이, 성향이 다른 가상 페르소나 네 명의 눈으로 테스트 과제(T1–T4)를 직접 따라가며 막힐 만한 곳을 찾은 전문가 리뷰입니다. 실제 테스트 전에 화면과 과제 문구를 고치는 데만 씁니다. 결과 표의 사용성 테스트 칸에는 넣지 않습니다.

- 일시: 2026-10-19
- 환경: 로컬 개발 서버, 테스트 모드 `#/app?study=P01` (T1 매번 확인 → T2 담기만 확인 → T3 알아서 → T4 가격 대기), 데스크톱 1440px과 모바일 375px
- 방법: 과제마다 화면에 나온 문구를 그대로 기록하고, 페르소나별로 "여기서 무엇을 보고, 무엇을 누를까, 무엇을 오해할까"를 적었습니다.

| | 페르소나 | 성향 | 이 사람이 드러내는 위험 |
|---|---|---|---|
| A | AI가 낯선 실속형 | 온라인 쇼핑은 자주, AI 어시스턴트는 거의 안 씀. 문구를 그대로 믿음 | 화면 문구와 실제 동작이 다르면 그대로 오해한다 |

## 페르소나별로 본 과제 흐름 요약

- **A (AI가 낯선 실속형)**: T1 매번 확인은 순서가 분명해 무난합니다. T3에서 1번(모르는 표현)과 3번(인사 문구와 다른 동작)이 겹쳐, "말을 못 알아듣고, 말한 것과 다르게 행동한다"는 인상을 받을 가능성이 큽니다.
- **B (빠르게 누르는 사람)**: 2번에서 옛 금액 버튼을 누르고, 6번에서 같은 승인을 두 번 하게 됩니다. B에게 R4가 실제로 작동하는지는 2번을 고쳐야 제대로 측정됩니다.
- **C (꼼꼼한 비교형)**: 비교 화면(5번)과 '알아서'의 판매처 선택(7번)에서 근거를 찾지 못합니다. 설계상 근거는 있지만 화면에 닿지 않는 경우입니다.
- **D (휴대폰)**: T4가 사실상 막힙니다(8번). 대기를 시작했는지 알 수 없습니다.
